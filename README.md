\# Polo Fleet Payment Tracker



A PHP web application for Comsat to track payments, expenses, and driver activity for the Polo VW fleet.



\*\*Live site:\*\* https://polo.comsat.co.za



\---



\## 📖 About



The Polo VW fleet needed a simple way to record payments and expenses without relying on spreadsheets. This web app gives each user a secure login and role-based access, so drivers can log their activity while management sees the full picture.



\---



\## ✨ Features



\- 🔐 Secure login with role-based access (Admin / Manager / Driver)

\- 💰 Payment tracking per driver and vehicle

\- 📊 Expense management with totals

\- 📁 File uploads (proof of payment, receipts)

\- 👤 Personal dashboard ("me" view) for each user

\- 🔄 Session handling with logout

\- 🛠️ Setup script for first-time installation



\---



\## 🛠️ Tech Stack



\- \*\*Backend:\*\* PHP (PDO for database access)

\- \*\*Database:\*\* MySQL / MariaDB

\- \*\*Frontend:\*\* HTML, CSS, JavaScript

\- \*\*Auth:\*\* PHP sessions with role checks

\- \*\*Hosting:\*\* Xneelo (South Africa)
